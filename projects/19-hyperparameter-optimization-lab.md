# 19. Hyperparameter Optimization Lab

## Goal
Build and evaluate a robust ML experiment rather than optimizing a single score.

## Build
- [ ] Define dataset and evaluation protocol
- [ ] Implement a baseline
- [ ] Compare multiple approaches
- [ ] Track metrics and runtime
- [ ] Perform error analysis
- [ ] Document reproducibility and trade-offs

## Interview
Explain metric selection, validation strategy, leakage risks, failure cases and what you would monitor after deployment.

## Stretch
Add experiment tracking, versioned artifacts and automated reports.
