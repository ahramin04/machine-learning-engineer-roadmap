# 03. Linear Regression from Scratch

## Goal
Build a measurable ML artifact with reliable data handling and evaluation.

## Build
- [ ] Define target and acceptance criteria
- [ ] Validate the data
- [ ] Create a leakage-safe split
- [ ] Establish a simple baseline
- [ ] Train and compare approaches
- [ ] Choose appropriate metrics
- [ ] Perform error analysis
- [ ] Document reproducibility and limitations

## Interview
Where can leakage occur? Why this metric? What is your baseline? What happens under distribution shift? How would you monitor it?
