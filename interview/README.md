# ML Engineer Interview Pack

Use **Problem → Data → Baseline → Model → Metric → Failure → Deployment → Monitoring**.

## Core topics
- Bias/variance, regularization and generalization
- Data leakage and train/validation/test design
- Feature engineering and selection
- Classification/regression metrics and thresholding
- Cross-validation and tuning
- Imbalanced data and calibration
- Trees, ensembles and gradient boosting
- Neural networks, backpropagation and optimizers
- CNNs, transfer learning and embeddings
- NLP and transformer foundations
- Batch vs online inference
- Reproducibility and model registries
- Feature stores
- Drift, monitoring and retraining
- Scaling inference and cloud deployment

## Practice
For every project explain: why this baseline, why this metric, where leakage can happen, what changes under distribution shift, how you would serve it at 10x traffic, and what triggers retraining.
