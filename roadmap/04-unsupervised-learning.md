# Stage 4: Unsupervised Learning

## Learn
Study the core concepts, implement one component from scratch, then reproduce it with a standard library/framework.

## Practice loop
1. Learn the concept.
2. Establish a simple baseline.
3. Experiment and measure.
4. Perform error analysis.
5. Document failure modes and trade-offs.
6. Explain production implications.

## Exit criteria
- [ ] Explain the concept intuitively
- [ ] Implement a minimal version
- [ ] Evaluate it correctly
- [ ] Identify leakage/failure modes
- [ ] Explain deployment implications
